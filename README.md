# taskproject

PHP pure project — Tasks + Auth (PDO + MySQL)

## إعداد
1. استورد SQL: `sql/create_tables.sql` في MySQL.
2. قم بتعديل `config/config.php` بقيم الاتصال.
3. شغّل:
   - `composer dump-autoload`
   - ثم من مجلد المشروع:
     `php -S localhost:8000 -t public`
4. افتح `http://localhost:8000/`
